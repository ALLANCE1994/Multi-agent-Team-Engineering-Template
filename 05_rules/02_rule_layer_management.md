
## 六、硬件小步快跑第零步（新增常驻规则）

> **来源**：参考项目经验二次学习收获

### 6.1 核心原则

**硬件操作前必须执行安全互锁检查，作为任何硬件操作的第零步。**

### 6.2 执行流程

```
任何硬件操作请求
    │
    ▼
【第零步】安全互锁检查（强制执行）
    ├─ 激光功率是否在安全阈值内？
    ├─ 高压电源是否已确认？
    ├─ 设备状态是否正常？
    └─ 参数是否在有效范围内？
    │
    ├─ 全部通过 → 继续执行
    └─ 任一失败 → 立即中止，输出安全警告
```

### 6.3 适用智能体

| 智能体 | 检查项 |
|--------|--------|
| @H 硬件工程师 | 时序约束、引脚配置、电源状态 |
| @Q 量子科学家 | 激光功率、实验参数、设备状态 |
| @S 软件工程师 | 驱动状态、通信链路、缓冲区状态 |

## 七、三层回滚防线（新增常驻规则）

> **来源**：参考项目经验二次学习收获

### 7.1 核心原则

**硬件工程采用三层回滚防线，确保任何变更可追溯、可回退、可隔离。**

### 7.2 三层定义

| 层级 | 机制 | 适用场景 | 响应速度 |
|------|------|----------|----------|
| **第一层** | Feature Flags（运行时开关） | 安全模式/全功能模式切换 | 毫秒级 |
| **第二层** | git revert（配置层回滚） | 配置变更原子化提交，精准回退 | 分钟级 |
| **第三层** | Worktree（物理层隔离） | 高风险实验在隔离工作目录进行 | 小时级 |

### 7.3 使用场景

| 场景 | 推荐层级 |
|------|----------|
| 临时禁用某功能（如高功率模式） | 第一层：Feature Flags |
| 配置参数错误需要回退 | 第二层：git revert |
| 高风险实验（如高功率激光测试） | 第三层：Worktree 隔离 |

### 7.4 执行示例

```bash
# 第一层：运行时开关
export NV_SAFE_MODE=1  # 启用安全模式

# 第二层：配置回滚
git revert HEAD~1  # 回退最近一次配置变更

# 第三层：物理隔离
git worktree add ../nv-experiment-high-power main  # 创建隔离工作目录
```
